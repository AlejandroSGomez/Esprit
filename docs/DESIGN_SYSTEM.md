# Diseño

Paleta inicial «Papel y tinta»: papel cálido, índigo, coral y texto oscuro.
Conserva legibilidad, estados de foco visibles, contraste y modo oscuro.
No contiene decoraciones del autor. La atribución es «Creada por A.S. Gómez».
Cada usuario puede elegir colores, fondo e icono; Claude debe mostrar el resultado
y revisar contraste y distribución después de un cambio visual.
